# Formula 1 Racing Management System (PES DBMS Level 3)

## Tech Stack
- **Frontend/Backend:** Next.js (App Router, API Route Handlers)
- **Primary DB (SQL):** MySQL / PostgreSQL (8 Normalized Tables)
- **Secondary DB (NoSQL):** MongoDB (Unstructured Telemetry & Pit-Stop Logs)
- **Auth:** NextAuth (Role-Based Access Control: Admin vs. Viewer)
